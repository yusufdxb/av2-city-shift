# v2 evidence and reproduction

v2 tests how far the original stopped-agent finding extends. The primary replication uses three new focal-only
checkpoints and a 10,000-scene training-split reserve excluded from every compared training draw. A separate QCNet
extension uses validation scenes because that published model trained on the training split. The original stages
and their verdicts remain frozen.

## Results and scope

| Extension | Result | Interpretation |
|---|---|---|
| R: fresh checkpoints and reserve | PATCH reduces the braking proxy by 61.2% [55.5, 66.4]; its advantage over the dose-matched sham is 29.3 pp [21.8, 37.1] | Both registered bars pass in the primary stop-line harness |
| R: moving-mode trimming | 60.3% [54.6, 65.4] fewer braking-proxy events | Registered replication component passes |
| G: probability versus geometry | Probability-only achieves 97.6% [94.9, 100.8] of PATCH's reduction; geometry-only achieves 0.34% [-0.88, 1.61] | Probability is sufficient under the registered ratio rule, within this model and planner |
| Q: stronger released forecaster | QCNet stopped-agent miss rate 2.29%, CV-6 9.46%, small model 52.46%; focal minFDE 1.253 m and miss rate 0.157 | The adapter control passes; the stopped-agent reversal does not generalise to QCNet |
| F: fixed horizons and complete futures | Two-second stopped-agent miss rates: small model 1.84% versus CV-6 3.75% at handoff; 1.46% versus 3.81% at the late replan | The registered persistence claim is killed; the original six-second finding is horizon-dependent |
| H: shared evaluation-scene covariance | H3 amended 98.75% interval [-0.0160, +0.0271] | No detectable difference, unchanged from the original verdict |
| S: training selection | Stopped non-focal miss rate falls from 56.23% to 7.38%, versus 57.56% for the selection sham | S1 and S2 pass; removing stopped-then-departing examples changes this error |
| S: downstream braking | 8.6% [0.2, 15.3] reduction; focal miss rate rises from 22.70% to 26.15% | S3 is killed: it misses the registered 30% bar and has an accuracy cost |
| Q: planning | 66 baseline events across 6,000 scenes; QCNet/oracle brake-rate ratio 1.35, below the required 2 | Q2 and Q3 are uninterpretable; control and power gates fail |

R/G intervals above are 98.75%. Q1 and S use 98.33% intervals; F's exploratory conjunction uses 95% intervals. Effect
estimates weight cities equally; the headline brake rates in the JSON pool scenarios after averaging fixed seeds.
These are different summaries. All intervals condition on the released checkpoints and the six observed cities.
Replaying all 210,000 primary replication drives finds no infeasible replans and no drive more than 1 cm past
the route end ([compliance diagnostic](../reports/v2/study_r_stopline_diagnostics.json)).
The same check passes on all 54,000 Q drives and 60,000 selection-treatment/sham drives:
[Q](../reports/v2/study_q_stopline_diagnostics.json),
[SEL](../reports/v2/study_s_sel_stopline_diagnostics.json),
[SELSHAM](../reports/v2/study_s_sham_stopline_diagnostics.json).
All 37 completed study checkpoints pass the [training integrity checks](../reports/v2/training_validation.json).

The completed training-selection (S), QCNet planning (Q2/Q3) and full-drive secondary results are reported in
[S open loop](../reports/v2/study_s_open.json), [S braking](../reports/v2/study_s_closed.json),
[Q planning](../reports/v2/study_q_closed.json) and [R/G secondary](../reports/v2/study_r_v2.json).
Every registered component retains its own control, power gate and verdict; an open-loop improvement alone does
not establish a braking benefit.

Selection lowers stopped non-focal misses by 48.85 pp [48.06, 49.65] relative to ALLR and 50.18 pp [49.40, 50.95]
relative to SELSHAM. Moving non-focal miss rates are 29.26%, 27.89% and 28.26% for ALLR, SEL and SELSHAM;
stopped focal miss rates are 25.52%, 48.99% and 25.80%. The intervention changes both the stopped-focal frequency
and its departure association, so it does not separate these mechanisms. Its open-loop success does not establish
a 30% downstream braking improvement.

QCNet's pooled brake rates are 1.10% baseline, 0.85% PATCH and 1.27% sham, versus 0.82% for oracle and 6.19%
for the small model. These pooled summaries do not replace the registered city-equal estimator. Palo Alto has zero
QCNet baseline events, making its relative reduction undefined and every city-equal bootstrap ratio undefined.
The failed control takes precedence in the registered verdicts; the 100-event and nonzero-city power rules also fail.

In the full-drive secondary harness, R's PATCH reduction is 33.2% [27.9, 38.0], with a 31.9 pp [26.1, 38.5]
advantage over the sham (95% intervals). Probability-only recovers 100.1% [94.3, 106.5] of PATCH's effect.
These secondary findings retain the full-drive harness's route-extension limitation.

The stricter excess-braking outcome is secondary. In the stop-line harness the baseline rate is only 0.243% of drives;
PATCH reduces it by 77.8% [58.3, 90.2], but its advantage over the sham is 12.6 pp [-4.5, 33.0], with 1.85% undefined
bootstrap ratios. This outcome does not establish the same targeting advantage as the original braking proxy.
Replans without complete logged futures cannot qualify, so this rate counts observed qualifying events rather than
judging every hard brake.
See [stop-line excess braking](../reports/v2/excess_brake_v4.json) and
[full-drive excess braking](../reports/v2/excess_brake_v2.json).
In the latter, 40.14% of bootstrap ratios are undefined. Its finite-draw interval is conditional on an estimable draw,
so it does not support an unconditional targeting claim despite the positive point estimate.

The planner controls speed along a privileged logged route, and surrounding agents replay logs without reacting.
Stop-line collisions have no working discrimination control; full-drive collisions largely measure route extension.
Neither collision comparison establishes driving safety.

## Registrations and corrections

The four registrations fix the cohorts, sample sizes, model seeds, estimators, controls, thresholds and stopping rules:
[R/G](preregistration/v2-fresh-reserve.md), [Q](preregistration/v2-qcnet.md),
[S](preregistration/v2-selection.md) and [H/F](preregistration/v2-analysis-amendments.md).
They were committed before each extension's own scoring. H is explicitly a post-result analysis amendment and F is
exploratory; neither changes an original verdict.

The completion records these deviations:

- An interrupted SEL seed-0 attempt stopped at update 54,600 without a checkpoint. It was restarted with its original
  seed and recipe. All three seeds per treatment and sham are required; no outcome selected the replacement.
- The original QCNet open-loop runner omitted 1,978 agents without native forecasts, including 1,586 stopped
  non-focal agents. The corrected cohort adds the registered single-CV, probability-one fallback. Native forecasts
  remain unchanged. The original focal positive-control cohort was complete. Both the corrected full cohort and a
  labelled native-only sensitivity reject the stopped-agent reversal.
- The factorial identity control applies both changes at the same mode index selected from the original forecast.
  Reselecting after the geometry change is a different operation for nonzero stopped-agent speeds. Tests now cover
  those velocities; the separately generated GEO, PROB and PATCH arms did not change.
- Exact scene/agent pairing, all three seeds, finite outcomes and registered cohort digests are checked before
  inference. Twenty-three validation scenes have no selected planner agents at any scheduled F replan; a released
  empty-scene witness accounts for them, and the independent audit can check it against raw records.

The current QCNet result is `reports/v2/study_q_open_corrected.json`. `study_q_open_native.json` is the explicit
native-only sensitivity. `study_q_open.json` preserves the original, incomplete-cohort output and is not used for
current decisions.

Historical Q manifests identify the checkpoint, cohort, batching and shims but omit source and auxiliary small-model
checkpoint fingerprints. The completion supplies prospective source/checkpoint fingerprints, validated part
memberships and an input-content inventory. Those records do not reconstruct missing historical provenance.
Legacy `raw_root_sha256` values fingerprint a resolved path string, not raw-data content. The separately released
`input_fingerprints.json` hashes file content used in the completion. Its recording date is not evidence that the
same file bytes were used in every historical run.

## Reproduce the analyses on a CPU

The v2 assets are named:

- `av2-city-shift-v2-source.tar.gz`: committed public source and result summaries.
- `av2-city-shift-v2-tables.tar.gz`: all rows needed by both v2 audits, registered IDs, exclusions, flags, content
  fingerprints and completion provenance. Original H and Stage 3a reference tables are included.
- `av2-city-shift-v2-models.tar.gz`: ALL, ALLR, SEL and SELSHAM checkpoints, training draws, configurations and logs.
- `av2-city-shift-v2-report.pdf` and `av2-city-shift-v2-report-source.tar.gz`: rendered technical report and its source.
- `SHA256SUMS` and `manifest.json`: asset identity and source revision; `V2-LICENSE-NOTICE.txt` records the licensing.

With the prepared or downloaded source and table assets in an empty directory:

```bash
sha256sum --ignore-missing -c SHA256SUMS
tar xzf av2-city-shift-v2-source.tar.gz
tar xzf av2-city-shift-v2-tables.tar.gz
python -m venv .venv
. .venv/bin/activate
python -m pip install 'torch==2.11.0+cpu' --index-url https://download.pytorch.org/whl/cpu
python -m pip install -r requirements/ci.txt -e '.[dev,figures]'
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 python scripts/audit_v2.py --out audit-v2.json
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 python scripts/audit_v2_amendments.py --out audit-hf.json
pytest -q tests
```

Both audit JSON files must say `"pass": true`. Missing inputs fail; a subset audit does not certify all of v2.
The independent scripts import no `cityshift` implementation. They use fresh bootstrap draws, require matching
point estimates and verdicts, and allow interval endpoints to differ by at most 15% of the reported interval width
for Monte Carlo variation. The R/G/Q/S audit also checks cohorts, arm/seed pairing, dose, controls and power.
The excess-braking audit starts from released flags; it does not independently replay their generation.

Regenerate the current result summaries from the released rows:

```bash
python -m cityshift.analysis_v2 r --parts runs/v2/study_r_v4 --harness v4 --out /tmp/r-v4.json
python -m cityshift.analysis_v2 r --parts runs/v2/study_r_v2 --harness v2 --out /tmp/r-v2.json
python -m cityshift.analysis_v2 q-open --rows runs/v2/q_open --fallback runs/v2/q_open_fallback.parquet --out /tmp/q-open.json
python -m cityshift.analysis_v2 q-open --rows runs/v2/q_open --native-only --out /tmp/q-native.json
python -m cityshift.analysis_v2 q-closed --parts runs/v2/q_closed \
  --q-open reports/v2/study_q_open_corrected.json --out /tmp/q-closed.json
python -m cityshift.analysis_v2 s-open --rows runs/v2/study_s_open --out /tmp/s-open.json
python -m cityshift.analysis_v2 s-closed --out /tmp/s-closed.json
python -m cityshift.h3_shared --evals evals --out /tmp/h.json
python -m cityshift.coverage --parquet 'runs/v2/coverage/*.parquet' --out /tmp/f.json
```

The report-source asset includes generated numbers and figures. After extraction, compile on a CPU with
`cd paper`, then `pdflatex main.tex`, `bibtex main`, and `pdflatex main.tex` twice. Full regeneration with `make`
also needs the original v1 evidence assets described in the main README; the v2 table asset includes only the
original rows used by the v2 analyses.

## Reproduce training and scoring

Raw-data reproduction requires the licensed AV2 training and validation splits, the preprocessed arrays from the
main README, the model asset, and one CUDA GPU. Extract the model asset into the checkout. Its configurations use
portable paths. Tensor values are identical to the original checkpoints; serialization hashes differ because
private filesystem paths were removed. `provenance/v2-models-inventory.json` records both hashes and a tensor digest.
Existing run manifests refer to the original checkpoint files, so score into new output directories.

For each seed 0, 1 and 2, use the registered recipe. Example for selection seed 0:

```bash
python -m cityshift.train --root data/pp --out runs/reproduction/SEL/seed0 --seed 0 \
  --n-train 128000 --steps 60000 --batch 128 --lr 0.001 --exclude-ids runs/v2/selection/SEL_exclude.npy
```

Repeat for SELSHAM with its exclusion file and for ALLR with `runs/v2/reserve_ids.npy`. The exclusion files and draw
fingerprints are released. `make_reserve.py` and `make_selection_sets.py` reconstruct them from preprocessing and
the original Stage 4 pool. Do not draw a new reserve or substitute partially trained seeds.

```bash
python -m cityshift.study_r --raw data/raw/train --harness v4 --out-dir runs/reproduction/r-v4
python -m cityshift.study_r --raw data/raw/train --harness v2 --out-dir runs/reproduction/r-v2
python -m cityshift.study_s --root data/pp --raw data/raw/train --out-dir runs/reproduction/s-open
python -m cityshift.study_r --raw data/raw/train --runs runs/v2/completion/SEL \
  --harness v4 --arms ALL --out-dir runs/reproduction/s-sel
python -m cityshift.study_r --raw data/raw/train --runs runs/v2/completion/SELSHAM \
  --harness v4 --arms ALL --out-dir runs/reproduction/s-sham
python -m cityshift.excess_brake --raw data/raw/train --parts runs/v2/study_r_v4 --harness v4 \
  --out /tmp/excess-v4.json --flags-out /tmp/excess-v4.parquet
python -m cityshift.coverage --raw data/raw/val --device cuda --out runs/reproduction/coverage.parquet
```

These commands use the released model locations by default. Pass `--runs`/`--allr` to select newly trained
reproduction checkpoints. Checkpoint validation and the exact reserve digest run before Study S scoring.

QCNet is external and is not redistributed. Use [the official repository](https://github.com/ZikangZhou/QCNet)
at revision `55cacb418cbbce3753119c1f157360e66993d0d0`, its dependencies, the AV2 API and the official
`QCNet_AV2.ckpt`. Verify its SHA-256:
`b9f852ec888d6fb966a38e3e307af231145b8e1e69cf7b0b9dddd1ae33120f21`.
The completed adapter run used PyTorch 2.11.0, PyG 2.8.0.post1, PyTorch Lightning 2.6.1 and AV2 0.3.6; the manifest
records the adapter shims. The public checkpoint's training recipe differs from the small model in multiple ways.

```bash
python -m cityshift.study_q --mode open --raw data/raw/val --qcnet-root external/QCNet \
  --ckpt external/QCNet_AV2.ckpt --out-dir runs/reproduction/q-open --chunk 400 --batch 2
python -m cityshift.study_q --mode closed --raw data/raw/val --qcnet-root external/QCNet \
  --ckpt external/QCNet_AV2.ckpt --out-dir runs/reproduction/q-closed --chunk 300 --batch 4
```

The updated open-loop runner includes unavailable-forecast fallback rows directly. Do not append the historical
fallback-recovery table to a fresh full-cohort run. The `q_fallback` module exists to reconstruct the omitted rows
of the historical native-only pass. All Q scoring uses validation, never the training-split reserve.
